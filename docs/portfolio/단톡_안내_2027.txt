# 2027년 졸업생 단톡방 안내 — 메시지 두 개로 나눠 보낸다
# (2번은 학생이 길게 눌러 통째로 복사하기 쉽게 따로 보냄. [날짜]·[제출처]만 채워서 보낼 것)

────────────── 메시지 1 · 안내 ──────────────
[졸업생 포트폴리오 제출 안내]

학과 홈페이지 졸업생 페이지에 올릴 포트폴리오를 받아요!
다 같은 형식이어야 올리기 편해서, 아래처럼 정리해서 보내 주세요.

1. Claude나 ChatGPT에 내 포트폴리오 PDF 첨부
2. 다음 메시지(프롬프트)를 통째로 복사해서 같이 보내기
3. 나온 결과 직접 읽고 고치기 + [직접 입력] 칸·팀원 이름·관련 링크 채우기
4. 결과를 txt로 저장
5. 아래 모양으로 폴더를 만들어 폴더째(또는 zip) 제출

2027_이름/
├ 2027_이름.txt  (4번 결과)
├ 2027_이름.pdf  (원본 포트폴리오)
├ 1_프로젝트제목/  (txt의 [프로젝트 1])
│ ├ 썸네일.jpg  (대표 이미지 1장, 가로형 4:3 권장)
│ ├ 01.jpg
│ └ 02.jpg …  (보여 줄 순서대로, 최대 10장)
└ 2_프로젝트제목/ …

이미지: jpg·png, 긴 변 1600px 이상 (gif·영상은 txt의 영상 링크로)
마감: [날짜] / 제출처: [제출처]

※ AI가 없는 내용을 지어낼 수 있어요. 검증은 꼭 본인이 해 주세요!
※ PDF는 사이트에 그대로 올라가요. 전화번호·생년월일·주소는 지운 PDF로 보내 주세요.
※ 폴더 앞 번호는 txt의 [프로젝트 N] 번호와 같게 맞춰 주세요.
※ 팀 프로젝트는 팀원 이름을 꼭 적어 주세요. 우리 졸업생이면 그 친구 페이지에도 자동으로 연결돼요.
※ 프로젝트 사이트·깃허브·스토어 등 링크는 '관련 링크'에 여러 개 적어도 돼요.
※ 포트폴리오에 넣은 프로젝트는 학생 작품(쇼케이스)에도 기간순으로 같이 올라가요. 프로필 사진은 학과에서 찍은 걸로 올라가요.

────────────── 메시지 2 · 프롬프트 ──────────────
첨부한 내 포트폴리오 PDF를 아래 [양식]대로 정리해줘.

규칙
- "=== 출력 시작 ===" 부터 "=== 출력 끝 ===" 까지만, 마크다운 없이 순수 텍스트로 출력
- 콜론 앞 항목 이름은 바꾸지 말고, 괄호 안 안내는 지우고 값만 쓰기
- 포트폴리오에 없는 내용은 지어내지 말고 비워 두기 (수치·수상·회사·팀원 이름·날짜는 특히)
- [직접 입력] 칸은 그대로 두기
- 문장은 담백한 서술형(~했다), 괄호 안 숫자는 최대 글자 수
- 프로젝트는 나온 순서대로 최대 6개, [프로젝트 2]부터는 [프로젝트 1]과 같은 항목 반복
- 분야는 이 중에서만: 영상, 모션, 그래픽, 웹, UX/UI, 사진, 3D, XR, 게임, AI, 사운드, 인터랙티브, 기획
- 기간은 포트폴리오에 적힌 진행 기간을 연.월로 (예: 2025.03–2025.06), 월을 모르면 연도만
- 팀원은 포트폴리오에 적힌 이름만 쉼표로 (본인 제외), 없으면 비워 두기
- 관련 링크 = 그 프로젝트 사이트·깃허브·비핸스·스토어 등 포트폴리오에 적힌 주소만, 한 줄에 하나씩 "이름 | 주소" (영상은 영상 링크 칸에)
- 이미지 쪽 = 그 프로젝트가 실린 PDF 쪽 번호(쉼표로), 대표 이미지 쪽 = 그중 한 쪽
- 영문 항목은 자연스러운 영어로 번역
- 마지막 [AI 확인 메모]에 확인이 필요한 것 적기
